# BC 配音与视频工具首次安装说明

适用于第一次在 Windows 电脑上安装。日常操作以 Codex 为入口；API Key 等涉密内容只在本机配置程序中填写。

## 一、准备文件

需要三个官方安装包：

1. `env4BC-v1.1.0.zip`：环境工具。
2. `voice-production-toolkit-v3.0.zip`：配音工具。
3. `word2video4BC-v2.0.0.zip`：视频工具。

官方 Release：

- env4BC：<https://github.com/zjw051230-jpg/env4BC/releases/tag/v1.1.0>
- 配音工具：<https://github.com/zjw051230-jpg/voice-production-toolkit4bingchuan/releases/tag/v3.0.0>
- 视频工具：<https://github.com/zjw051230-jpg/word2video4BC/releases/tag/v2.0.0>

只使用官方 Release，并保留同名 `.sha256` 校验文件。不要从第三方网站下载安装包。

## 二、让 Codex 安装

把下载的三个 ZIP 放在本机目录中，然后把下面这段话发给 Codex，并把尖括号中的路径换成真实路径：

```text
请首次安装 BC 配音与视频工具。

env4BC 安装包：<env4BC ZIP 的完整路径>
配音工具安装包：<配音 v3.0 ZIP 的完整路径>
视频工具安装包：<视频 v2.0 ZIP 的完整路径>

请先读取三个安装包内的 README、manifest 和首次安装说明，再按 env4BC、配音工具、视频工具的顺序安装。每个 ZIP 必须使用旁边的 .sha256 文件校验。严格执行“缺什么改什么”：已有相同工具跳过，发现不同版本先保留并报告，不得未经批准覆盖。

只允许安装或更新工具清单声明的文件。禁止扫描、整理、移动、改名、覆盖或删除项目素材、生成视频、MP3、交付版本、快照、日志、隐藏任务记录、API 私有配置、CC Switch 数据库和 provider。不要向服务器或共享目录复制任何文件。

环境不足时依次使用：已安装 env4BC、本机带正确 SHA-256 的 env4BC 包、官方 zjw051230-jpg/env4BC Release。仍无法安全补齐时立即停止并告诉我联系维护人员，禁止使用第三方来源。

安装完成后报告实际安装版本、工作区位置、隐藏更新记录位置和验证结果。
```

Codex 会询问工作区位置和首个项目名称。建议把工作区放在本机数据盘，不要默认放到服务器或共享盘。

## 三、配置 API

安装完成后打开 `Seedance API配置工具`，在本机窗口中填写 API Key。不要把 API Key 发到聊天、截图、日志或 GitHub。

CC Switch 和精确模型路由由 env4BC 管理。只允许精确映射 `gpt-5.5 -> deepseek-v4-pro`，不得改变其他模型映射、provider、API Key 或 base URL。

## 四、创建项目

配音项目：

```text
我要创建配音项目，名字叫“项目名”。
```

视频项目：

```text
我要创建视频项目，名字叫“项目名”。
```

Codex 会继续询问需要的剧本、台词、角色素材、任务资料和本机交付位置。

## 五、以后更新

首次安装会在工作区隐藏目录中保存官方 GitHub 地址、当前版本和安全更新脚本。以后不需要再次发送 GitHub 链接，只需要对 Codex 提一句：

```text
更新配音工具。
```

或：

```text
更新视频工具。
```

Codex 会从隐藏记录读取唯一官方仓库，下载最新正式 Release，校验 SHA-256，并且只更新工具白名单。不会对整个工作区执行 `git pull`，也不会修改项目素材、成品、API 配置、日志、快照或隐藏任务记录。

如果隐藏更新记录丢失，Codex 才会再次询问一次官方 GitHub 链接。发现来源不可信、校验失败或环境无法安全补齐时，Codex 必须停止并提示联系维护人员。

## 六、安装后检查

确认以下项目：

- env4BC、配音工具和视频工具均报告正确版本。
- 工作区隐藏更新记录存在。
- 配音任务看板可以启动。
- Seedance API 配置工具可以打开，但密钥不会显示在日志中。
- 原有素材、成品、项目、日志和隐藏记录没有被移动或修改。
- 安装过程没有向服务器、共享目录或第三方网站复制文件。
